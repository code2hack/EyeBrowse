## Settled design reminders

RG-only **480 wide × 640 high, portrait**. Top row stays `× | ← | → | ↻ | [short address + fixed clickable ☆/★] | i/n | ⋮`. More stays Add new tab / Bookmarks / QR scan / Settings. All first-party backgrounds black; contents light. No bottom toolbar, recenter control or browsing modes.

Settings uses `label [←] value [→]`, not preset buttons. Pointer 0.1×–6.0×/step0.1/default2.0×; scroll 10–1,200 px/s/step10/default240. Logical top/bottom strips are 24 px; invisible pointer still tracks/scrolls until visible re-entry. Left/right bounded; off-screen tap does nothing; outer excess discarded.

Proxy content is only names + independent ON/OFF + Delete + Add a new profile. Multiple ON profiles feed one global eligible-node pool. The core stays Rule mode; DIRECT does not compete as a normal lowest-delay node. No usable candidate, including all-unhealthy, means DIRECT. EyeBrowse owns China/local/tailnet routing and regional data; subscription data supplies nodes only. Same source URL updates, different URL adds; secrets private. All saved sources including OFF refresh every 30 minutes; deleted sources stop. No dashboard, normal-QR subscription guessing or system VPN is introduced.
