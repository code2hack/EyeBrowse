# EyeBrowse

EyeBrowse is an AI-native Android browser project targeting both Android phones and Rokid Glasses.

This repository is currently in the scaffold/specification phase. Production implementation has not started.

## Repository shape

- `app-phone/` — Android phone edition shell.
- `app-rg/` — Rokid Glasses edition shell.
- `core/` — shared browser, agent, speech, networking, and state platform.
- `design/` — authoritative design inputs and selected Product Design evidence.
- `docs/` — architecture and decision records as they are established.

`SPEC.md`, `AGENTS.md`, and `MILESTONES.md` are intentionally empty until their contents are explicitly designed.
