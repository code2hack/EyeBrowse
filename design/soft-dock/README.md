# Soft Dock design evidence

Soft Dock was selected as the MVP visual direction on 2026-09-08.

This directory stores curated design evidence that may inform `SPEC.md` and implementation. It does **not** define the production Android architecture by itself.

Included here:

- `design-decisions.md` — selected direction, target viewports, established interactions, and unresolved assumptions.
- `design-qa.md` — Product Design prototype QA and remaining real-device questions.

The disposable Product Design React/Vite prototype is intentionally not part of the production source scaffold. The selected reference image and full study archive can be added later as binary design artifacts if desired.
